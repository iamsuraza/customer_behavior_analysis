# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior to uncover patterns in purchasing, customer segments, product performance, discounts, shipping preferences, and subscription behavior.

The project combines **Python, PostgreSQL/SQL, and Power BI** to create an end-to-end data analytics workflow:

1. Clean and prepare the raw customer shopping dataset using Python.
2. Engineer additional analytical features such as age groups and purchase frequency in days.
3. Load the transformed data into PostgreSQL.
4. Use SQL to answer key business questions.
5. Visualize and communicate the analysis through a Power BI dashboard.

## Project Objectives

The main objectives of this analysis are to:

- Understand customer purchasing behavior.
- Compare revenue across customer demographics.
- Identify high-performing products.
- Analyze the impact of discounts and subscriptions.
- Compare shipping methods.
- Segment customers based on previous purchases.
- Examine repeat-buyer and subscription behavior.
- Analyze revenue contribution across age groups.

## Data Preparation

The Jupyter Notebook performs the following preprocessing steps:

### 1. Data inspection

The dataset is loaded into a Pandas DataFrame and inspected using:

- `head()`
- `info()`
- `describe()`
- Missing-value checks

### 2. Missing-value treatment

Missing values in **Review Rating** are filled using the median review rating within each product category.

### 3. Column standardization

Column names are converted to lowercase and spaces are replaced with underscores.

For example:

```text
Purchase Amount (USD)
```

is renamed to:

```text
purchase_amount
```

### 4. Age-group creation

Customers are divided into four age groups using quartiles:

- Young Adult
- Adult
- Middle-aged
- Senior

### 5. Purchase-frequency transformation

Purchase-frequency categories are converted into the corresponding number of days.

Examples:

| Frequency | Days |
|---|---:|
| Weekly | 7 |
| Fortnightly | 14 |
| Bi-Weekly | 14 |
| Monthly | 30 |
| Quarterly | 90 |
| Every 3 Months | 90 |
| Annualy | 365 |

### 6. Redundant-column removal

The notebook checks the relationship between `discount_applied` and `promo_code_used` and removes `promo_code_used` from the final dataset.

## PostgreSQL Integration

The transformed DataFrame is loaded into PostgreSQL using SQLAlchemy.

The database configuration used by the notebook expects:

```text
Table: customer

```

## SQL Analysis

The SQL analysis answers the following business questions:

### 1. Revenue by Gender

Compares total revenue generated by male and female customers.

### 2. Discounted Purchases Above Average

Identifies customers who used a discount while spending at least the average purchase amount.

### 3. Top Products by Average Review Rating

Finds the five products with the highest average review rating.

### 4. Standard vs Express Shipping

Compares the average purchase amount for Standard and Express shipping.

### 5. Subscriber vs Non-Subscriber Spending

Compares:

- Number of customers
- Average spending
- Total revenue

between subscribers and non-subscribers.

### 6. Products with the Highest Discount Rate

Calculates the percentage of purchases where a discount was applied for each product.

### 7. Customer Segmentation

Customers are segmented using their number of previous purchases:

| Previous Purchases | Segment |
|---|---|
| 1 | New |
| 2–10 | Returning |
| More than 10 | Loyal |

### 8. Top Products Within Each Category

Uses a window function to identify the three most purchased products within each product category.

### 9. Repeat Buyers and Subscription Status

Examines the subscription status of customers who have made more than five previous purchases.

### 10. Revenue by Age Group

Calculates total revenue contributed by each age group.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Jupyter Notebook or JupyterLab
- PostgreSQL
- pgAdmin (optional)
- Power BI Desktop

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Customer-Shopping-Behavior-Analysis
```

### 2. Install Python Dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### 3. Open the Notebook

```bash
jupyter notebook Customer_Shopping_Behavior_Analysis.ipynb
```

### 4. Prepare PostgreSQL

Create a PostgreSQL database named:

```text
customer_behavior
```

Then update the database connection details in the notebook with your own credentials.

### 5. Load the Data

Run the notebook cells to:

- Load the dataset.
- Clean the data.
- Create analytical columns.
- Connect to PostgreSQL.
- Load the transformed DataFrame into the `customer` table.

### 6. Run the SQL Analysis

Open:

```text
Customer_Shopping_Behavior_Analysis.sql
```

and execute the queries against the PostgreSQL `customer` table.

### 7. Open the Power BI Dashboard

Open:

```text
Customer_Shopping_Behavior_Analysis.pbix
```

in Power BI Desktop to explore the dashboard.
